# Holon Rental Monitor

בודק כל 3 שעות מודעות חדשות בפייסבוק וביד2, מסנן לפי הקריטריונים שהוגדרו ושולח מייל רק על מודעות חדשות או על בעיית גישה.

## מה כבר מוגדר

- חולון, עדיפות לאגרובנק
- 3.5–4.5 חדרים
- 4,000–7,100 ₪; מודעה בלי מחיר עדיין יכולה להישלח
- חניה פרטית ששייכת לדירה חובה
- חניה ברחוב/בסביבה נפסלת
- אם כתוב במפורש שאין ממ״ד — נפסל; אם לא מוזכר — מותר
- מרפסת בעדיפות
- כניסה לפחות 21 יום לאחר מועד הפרסום
- מניעת כפילויות באמצעות `seen.json`

## חשוב

הפרויקט לא עוקף הרשאות או חסימות. כדי לקרוא פייסבוק ויד2 צריך להגדיר Actors מתאימים ב-Apify ולפעול בהתאם לתנאי השימוש של האתרים.

## העלאה ל-GitHub

1. הורד את קובץ ה-ZIP וחלץ אותו.
2. ב-GitHub פתח את המאגר `holon-rental-monitor`.
3. לחץ **Add file → Upload files**.
4. גרור את כל הקבצים והתיקיות מתוך התיקייה שחולצה.
5. לחץ **Commit changes**.

## הגדרת Secrets

במאגר: **Settings → Secrets and variables → Actions → New repository secret**.

צור את הסודות הבאים:

- `APIFY_TOKEN`
- `APIFY_FB_ACTOR_ID`
- `APIFY_YAD2_ACTOR_ID`
- `SMTP_HOST` — לדוגמה `smtp.gmail.com`
- `SMTP_PORT` — בדרך כלל `587`
- `SMTP_USERNAME`
- `SMTP_PASSWORD` — App Password, לא הסיסמה הרגילה
- `SMTP_FROM` — בדרך כלל זהה ל-`SMTP_USERNAME`

## יד2

פתח `config.json` והדבק ב-`yad2_search_url` קישור לתוצאות חיפוש יד2 המסוננות שלך.

## בדיקה ידנית

במאגר לחץ **Actions → Holon rental monitor → Run workflow**.

אם הכול תקין, התהליך ירוץ אוטומטית כל 3 שעות.
